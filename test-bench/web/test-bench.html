Banc poêle 433

Déconnecté
Ce navigateur ne sait pas parler à l'USB. Ouvre cette page dans Chrome ou Edge (Web Serial).
Mode d'emploi

1. Ferme le moniteur série de l'IDE Arduino, puis clique sur Connecter l'ESP et choisis le port (COM7).

2. Avant chaque appui sur la télécommande, écris ce que tu vas faire dans le champ en haut, puis Poser un repère. Les trames qui suivent sont celles de ton appui.

3. L'onglet Trames distinctes regroupe les trames identiques. Une trame qui apparaît juste après un repère, et seulement là, est candidate pour être la commande. Clique sur Réf. pour la prendre comme référence : les bits qui diffèrent sur les autres trames s'affichent en rouge.

4. Émettre renvoie la trame par l'ESP. Coche plusieurs trames et clique sur Émettre la sélection pour rejouer une séquence avec ses écarts d'origine (par exemple l'annonce puis la commande).

5. Exporter sauvegarde la session dans un fichier, à garder ou à me transmettre.

Décodage : chaque tranche de l'unité (≈ 416,7 µs) donne un bit ; signal = 1, silence = 0. Les silences de 12 bits ou plus (synchro) sont affichés comme « ┃ ».

Composer une trame de télécommande (le 1er octet tapé est envoyé tel quel ; les boutons utilisent l'identifiant des Réglages) — octets en hexadécimal ; la somme de contrôle est ajoutée toute seule.
Touches connues : 00 interrogation, 84 bouton ventilateur, 98 bouton puissance (chacun ouvre ou referme son menu sur le poêle), 88 « + », 8C « − ». Deuxième octet : 3D repos, BD menu ouvert. « Ventilateur + » envoie C5 3D 00 84, attend la réponse du poêle, puis C5 BD 00 88.
